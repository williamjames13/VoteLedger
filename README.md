A blockchain-based anonymous voting system for schools using Stellar Soroban.

---

## Problem

Student elections in schools often rely on manual vote counting, causing delays, disputes, and lack of transparency.

## Solution

VoteLedger uses Stellar Soroban smart contracts to enable secure, anonymous, and tamper-proof voting with real-time counting.

# Vision and Purpose

VoteLedger aims to modernize student elections in Southeast Asia by providing transparent, low-cost, and trustworthy digital voting infrastructure.
